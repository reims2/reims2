# Edit or delete

In **Edit**, type the SKU, then click **Edit** or **Delete**.

## Edit

Correct the values and click **Save changes**.

![Edit dialog](/screenshots/edit-dialog.png)

## Delete

For missing or broken glasses. Pick a reason and click **Confirm deletion**. The reason shows up in the
[reports](./reports).

![Delete dialog](/screenshots/delete-dialog.png)

A deleted pair can be restored with **Undo**, like a dispensed one.
