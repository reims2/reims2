# Add glasses

1. In **Add**, pick category, frame appearance and frame size, and fill in both eyes.
2. Click **Add glasses**.
3. Mark the pair with its new SKU from **Recently added**.

![Add page](/screenshots/add.png)

::: tip Keyboard
The first letter picks an option, like `m` for multifocal. Press `A` to add.
:::

A pair added by mistake can be deleted right there. Adding needs internet.
